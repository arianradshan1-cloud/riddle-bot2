# ⚡ RadProtocol Media Downloader Bot

> ربات تلگرام دانلود همه‌کاره از شبکه‌های اجتماعی (اینستاگرام، تیک‌تاک، یوتیوب، توییتر و پینترست) همراه با سیستم قفل عضویت اجباری (Force Join) کانال **RadProtocol**.

طراحی‌شده برای استقرار سریع و رایگان روی سرورهای ابری **Render.com**.

---

## 🌟 ویژگی‌ها و امکانات

- 📱 **دانلود از اینستاگرام:** ریلز (Reels)، پست‌های تک و اسلایدی، ویدیوها بدون واترمارک و بدون نیاز به لاگین.
- 🎵 **دانلود از تیک‌تاک:** ویدیوهای HD بدون واترمارک + امکان استخراج مستقیم فایل صوتی (MP3).
- 🎬 **دانلود از یوتیوب:** دانلود Shorts و ویدیوها با بالاترین کیفیت موجود.
- 🐦 **دانلود از توییتر / X:** استخراج ویدیوی اصلی و تصاویر با کیفیت بالا.
- 📌 **دانلود از پینترست:** دانلود عکس‌ها و ویدیوهای پین‌شده با لینک مستقیم.
- 🔒 **سیستم قفل کانال (Force-Join):** تا کاربر در کانال `@rad_protocol` عضو نشود، اجازه دانلود داده نمی‌شود.
- 📊 **پنل مدیریت پیشرفته (`/admin`):** مشاهده آمار دقیق کاربران، تعداد دانلودها بر اساس هر پلتفرم و وضعیت سرور.
- 📢 **سیستم ارسال همگانی (`/broadcast`):** امکان ارسال اطلاعیه‌ها به تمام کاربران ربات به صورت آنی.
- ⚡️ **معماری هیبریدی Render:** سازگاری کامل با سیستم وب‌هوک (Webhook) رندر جهت بیداری خودکار سرور و حداقل مصرف رم و پردازنده.

## 🚀 راهنمای استقرار روی Render (Deployment)

### ۱. ساخت سرویس در Render
1. وارد سایت [Render.com](https://render.com) شوید.
2. روی دکمه **New +** کلیک کرده و گزینه **Web Service** را انتخاب کنید.
3. این ریپازیتوری (`riddle-bot2`) را متصل (Connect) کنید.
4. تنظیمات زیر را وارد کنید:
   - **Name:** `rad-downloader-bot` (یا نام دلخواه)
   - **Environment:** `Node`
   - **Build Command:** `npm run build`
   - **Start Command:** `npm start`
   - **Instance Type:** `Free`

### ۲. تنظیم متغیرهای محیطی (Environment Variables)
در بخش **Environment** داشبورد رندر، مقادیر زیر را اضافه کنید:

| کلید (Key) | مقدار (Value) | توضیح |
| :--- | :--- | :--- |
| `TELEGRAM_TOKEN` | توکن ربات از BotFather | توکن ربات تلگرام |
| `REQUIRED_CHANNEL` | `@rad_protocol` | کانال جهت قفل عضویت |
| `ADMIN_ID` | `123456789` | آیدی عددی تلگرام ادمین (از @userinfobot) |
| `CHANNEL_LINK` | `https://t.me/rad_protocol` | لینک عضویت کانال |
| `SUPPORT_GROUP` | `https://t.me/radprotocoll` | لینک گروه پشتیبانی |

روی دکمه **Deploy** کلیک کنید. پس از چند لحظه ربات شما به صورت ۲۴ ساعته فعال خواهد شد! 🚀

## 🛠 توسعه و اجرای محلی (Local)

```bash
# نصب وابستگی‌ها
npm install

# ساخت فایل تنظیمات
cp .env.example .env
# مقادیر توکن را در فایل .env وارد کنید

# اجرای ربات
npm start
```
