# 🐍 ربات مدیریت گروه تلگرام (تام ریدل / دن)

ربات تلگرامی با دو شخصیت قابل‌انتخاب (تام ریدل و دن)، متصل به Gemini API، با پنل مدیریتی شیشه‌ای،
سیستم امتیاز و مسابقه، فیلتر کلمات، قفل‌های گروه، و مدیریت چند کلید API.

## پیش‌نیازها

- یک ربات تلگرام ساخته‌شده از [@BotFather](https://t.me/BotFather) (توکن ربات رو ازش می‌گیری)
- یک کلید Gemini API از [Google AI Studio](https://aistudio.google.com/apikey)
- آیدی عددی تلگرام خودت به‌عنوان ارباب جوان (owner) — از [@userinfobot](https://t.me/userinfobot) بگیر
- یک حساب رایگان روی [Render.com](https://render.com)

## متغیرهای محیطی

اینا رو باید تو داشبورد Render (بخش Environment) وارد کنی:

| نام | توضیح |
|---|---|
| `TELEGRAM_TOKEN` | توکن ربات از BotFather |
| `GEMINI_API_KEY` | کلید پیش‌فرض Gemini (اگه از پنل ربات کلید دیگه‌ای فعال نکرده باشی، همینو استفاده می‌کنه) |
| `OWNER_ID` | آیدی عددی تلگرام ارباب جوان |
| `ADMIN_SECRET` | یک رشته‌ی تصادفی دلخواه (مثلاً یه پسورد طولانی) برای محافظت از مسیرهای مدیریتی |

`PUBLIC_URL` رو لازم نیست دستی ست کنی — Render خودش متغیر `RENDER_EXTERNAL_URL` رو می‌سازه و کد ازش استفاده می‌کنه.

## دیپلوی روی Render (از گوشی هم قابل انجامه)

1. کد رو تو یه ریپازیتوری GitHub بذار (می‌تونی از اپ یا مرورگر GitHub، فایل‌ها رو مستقیم پیست/آپلود کنی)
2. برو [render.com](https://render.com) و با گیت‌هابت لاگین کن
3. **New +** → **Web Service** رو بزن و ریپازیتوری رو انتخاب کن
4. تنظیمات:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
5. تو بخش **Environment**، چهار متغیر بالا رو اضافه کن
6. **Create Web Service** رو بزن و صبر کن دیپلوی تموم بشه

## وصل‌کردن وب‌هوک (فقط یه بار لازمه)

بعد از این‌که دیپلوی موفق شد، از مرورگر گوشیت این آدرس رو باز کن (به‌جای مقادیر داخل `<>` مقدار خودتو بذار):
اگه جواب `"ok":true` گرفتی، وب‌هوک وصل شد و ربات آماده‌ی کاره.

## نکته‌ی مهم درباره‌ی پلن رایگان Render

سرویس‌های رایگان Render بعد از ۱۵ دقیقه بدون درخواست، «می‌خوابن». وقتی کسی تو گروه پیام بده، تلگرام
درخواست وب‌هوک می‌فرسته و سرویس بیدار می‌شه، ولی ممکنه اولین جواب چند ثانیه تأخیر داشته باشه.

برای این‌که ربات همیشه بیدار بمونه، می‌تونی یه سرویس رایگان مثل
[UptimeRobot](https://uptimerobot.com) یا [cron-job.org](https://cron-job.org) رو تنظیم کنی که
هر ۱۰ دقیقه یه‌بار آدرس اصلی اپت (`https://<اسم-اپت>.onrender.com/`) رو پینگ کنه.

## پیام روزانه و خلاصه‌سازی خودکار

ربات به‌صورت داخلی سه‌تا کار زمان‌بندی‌شده داره (با `node-cron`)، ولی این‌ها فقط وقتی اجرا می‌شن
که سرویس در همون لحظه بیدار باشه:

- ساعت ۹ صبح تهران: پیام تِم روزانه
- ساعت ۲۳ شب تهران: خلاصه‌ی گفتگوهای روز
- ساعت ۴ بامداد تهران: پاک‌سازی آمار قدیمی

چون رو پلن رایگان ممکنه دقیقاً همون لحظه سرویس خواب باشه، **راه مطمئن‌تر** اینه که با
cron-job.org این سه آدرس رو دقیقاً سر همون ساعت‌ها (به وقت UTC) صدا بزنی تا خودش سرویس رو بیدار
کنه و کار رو انجام بده:

| کار | ساعت تهران | معادل UTC | آدرس |
|---|---|---|---|
| پیام روزانه | ۹:۰۰ | ۵:۳۰ | `/cron/daily-message?secret=<ADMIN_SECRET>` |
| خلاصه‌ی روزانه | ۲۳:۰۰ | ۱۹:۳۰ | `/cron/daily-summary?secret=<ADMIN_SECRET>` |
| پاک‌سازی | ۴:۰۰ | ۰:۳۰ | `/cron/cleanup?secret=<ADMIN_SECRET>` |

## محدودیت ذخیره‌سازی

داده‌های ربات (آمار، امتیازها، تنظیمات، فیلترها) تو یه فایل JSON روی دیسک سرویس نگه‌داری می‌شن.
روی پلن رایگان Render دیسک پایدار نیست، یعنی با هر دیپلوی جدید یا ری‌استارت، این فایل خالی می‌شه.
برای یه ربات گروهی کوچیک معمولاً مشکل بزرگی نیست، ولی اگه بعداً خواستی داده‌ها همیشه بمونن، باید
`store.js` رو با یه دیتابیس واقعی (مثلاً Postgres رایگان خود Render) جایگزین کنی.

## دستورات ربات

**همه‌ی اعضا:**
- `/منو` — باز کردن پنل شیشه‌ای
- `/امتیازها` — جدول افتخارات مسابقه
- `/آمار` — فعال‌ترین اعضای امروز
- `/قوانین` — نمایش قوانین گروه

**فقط ارباب جوان (owner):**
- `/بسته` و `/باز` — بستن/بازکردن در تالار برای بقیه
- `/فیلتر_اضافه <کلمه>` و `/فیلتر_حذف <کلمه>`
- `/قوانین_تنظیم <متن>`
- `/کلید_اضافه <API_KEY>` — افزودن کلید Gemini جدید (پیام حاوی کلید خودکار پاک می‌شه)
- `/مسابقه` — شروع یه سؤال مسابقه
- با ریپلای روی پیام یه عضو: `اخطار`, `سکوت`, `رفع سکوت`, `اخراج`, `طرد`, `مرگ‌خوار`, `ماگل`
